# Cyber Resilience SIG — Task Forces

This directory tracks the task forces operating under the Cyber Resilience SIG. Detailed charters, outputs, and meeting notes can be found in each task force's respective folder.

| Task Force | Focus Area | Status |
| :--- | :--- | :--- |
| **[Stewards and Maintainers](./steward-maintainers-tf/)** | Attestations, FOSS Stewards cybersecurity policy | **Active** |
| **[Manufacturers](./manufacturers-tf/)** | Due diligence | **Active** |
| **[FAQ](./faq-tf/)** | Development of the (CRA FAQ)[cra.orcwg.org] | **Active** |
| **[Inventory](./inventory-tf/)** | Collection of existing resources that can help to map existing solutions into CRA compliance processes | **On hold** |
| **[Vulnerability handling](./vulnerability-handling-tf/)** | Support to the definition of vulnerability handling processes for open source | **On hold** |
| **[Deliverables plan](./deliverables-plan-tf/)** | definition of the deliverables the ORC community intends to work on | **On hold** |
| **[Open Source Hardware](./open-source-hardware-tf/)** | Collection of inputs to get open source hardware reflected into CRA discussions | **Archieved** |


---

### **Status Key**
* **Active:** Work actively underway; accepting community contributions.
* **On hold:** Defining charter and seeking task force leads.
* **Archived:** Deliverables finalised or merged into core SIG resources.
