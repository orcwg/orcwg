# Manufacturers Task Force

The Stewards and Maintainers TF is a [task force](https://github.com/orcwg/orcwg/blob/main/working-mode.md#task-forces) of the [Cyber Resilience SIG](../README.md).

## Focus Area

* Support the development of the processes that manufacturers should implement to demonstrate compliance with the CRA when dealing with open source components
* Define a due diligence process for the integration of open source components in CRA-regulated products.

## Deliverables

Possible white paper on vulnerability handling
