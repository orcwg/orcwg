# Stewards and Maintainers Task Force

The Stewards and Maintaners TF is a [task force](https://github.com/orcwg/orcwg/blob/main/working-mode.md#task-forces) of the [Cyber Resilience SIG](../README.md).

## Focus Area

* Support to the implementation of the CRA for Open Source Stewards, maintainers of open source projects.
* Contribute to the development of the attestation program in support to Art. 25 of the Cyber Resilience Act

## Deliverables

Possible white paper on vulnerability handling
